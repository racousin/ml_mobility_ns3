Installation de NS-3.45 sur Ubuntu 22.04 : OK
------------------------------------------
$ cat /etc/os-release
$ sudo apt install git g++ clang python3 python3-pip cmake ninja-build tcpdump wireshark
$ python3 -m pip install --user cppyy==3.1.2
$ tar -jxvf ns-3.45.tar.bz2
$ cd ns-3.45
$ ./ns3 configure --enable-examples --enable-tests
$ ./ns3 build
$ ./test.py
$ ./ns3 run hello-simulator

Installation of the netmob25 mobility model in NS-3.45
------------------------------------------------------
- copy netmob25-mobility-model.h in ns-3.45/src/mobility/model
- copy netmob25-mobility-model.cc in ns-3.45/src/mobility/model
- add netmob25-mobility-model.h and netmob25-mobility-model.cc in the CMakeLists.txt in ns-3.45/src/mobility
- add netmob25-mobility-example.cc in ns-3.45/scratch
- Recompile NS3
$ cd ns-3.45
$ ./ns3 configure --enable-examples --enable-tests
$ ./ns3 build
- Test netmob25-mobility-example.cc
$ ./ns3 run scratch/netmob25-mobility-example.cc
